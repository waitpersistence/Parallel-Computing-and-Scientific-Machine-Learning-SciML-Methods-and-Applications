# Parallel Computing and Scientific Machine Learning (SciML) Methods and Applications

关于这门课用到的一些资料 | Resources and Materials for This Course

## 📚 Overview

This repository contains resources, notes, and implementations related to parallel computing and scientific machine learning methods, with a focus on numerical methods for differential equations and physics-informed neural networks.

---

## 🎯 Main Learning Objectives

### Key Topics Covered

1. **Numerical Methods for Ordinary Differential Equations (ODEs)**
   - Error estimation and analysis
   - Fixed-point iterations
   - Newton's method
   - Euler's method
   - Other advanced ODE solving techniques

2. **Physics-Informed Neural Networks (PINNs)**
   - Network architecture and design
   - Training strategies and optimization

3. **Partial Differential Equations (PDEs) Solving**
   - Deep learning approaches using BSNO (Basis State Neural Operator)
   - Traditional numerical methods

4. **Parallel Computing**
   - MPI (Message Passing Interface)
   - Distributed computing concepts
   - Performance optimization
